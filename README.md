# 컴포넌트 라벨러

폐쇄망 개발자에게 전달할 시안 이미지에 **코드 컴포넌트명 라벨**을 찍어 주는 사이트.
시안을 올리고 → 라벨을 찍고 → `화면명_original.png` + `화면명_labeled.png`를 zip으로 받는다.

## 기능 (MVP)

- 시안 등록: PNG·JPG 드래그 앤 드롭, 여러 장
- 라벨 편집: 드래그로 박스 추가, 이동·크기 조절, 카탈로그 자동완성으로 코드명 지정, variant 선택, 상태(매칭됨/확인 필요/미등록)
- AI 자동 라벨: Claude 비전으로 카탈로그 컴포넌트 위치를 찾아 (선택, 기본 화면에서는 꺼져 있음)
- Export: 원본과 같은 해상도의 라벨본 PNG + 원본 PNG를 zip으로. 태그가 겹치면 번호 마커 + 범례로 바뀐다
- 카탈로그 관리: 코드명·피그마명·import 경로·생김새 설명·variant·참고 이미지. 브라우저에 저장되고 JSON으로 내보내기/가져오기

시안 이미지는 브라우저 안에서만 처리된다. 외부로 나가는 건 **AI 자동 라벨** 버튼을 눌렀을 때뿐이다(Vercel 함수 → Anthropic API).

## 환경변수 (Vercel)

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | AI 자동 라벨을 쓸 때 | 없으면 AI 버튼만 안내 메시지를 띄우고 나머지는 그대로 동작 |
| `APP_PASSWORD` | 선택 | 설정하면 AI 호출 때 비밀번호를 묻는다 (API 비용 보호) |

## 개발

```bash
npm install
npm run dev      # 화면만 (api/ 함수는 vercel dev로)
npm run build
```

기본 카탈로그는 `public/catalog/` (피그마를 보고 만든 목 카탈로그)에서 처음 한 번 불러온다.
